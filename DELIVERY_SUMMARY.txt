📋 HOW TO USE

Accessing the Page:
1. Go to http://localhost:3000/admin
2. Click the "Vehicles & Rates" card (🚗 icon)
3. You'll be taken to /admin/vehicles

Creating a Vehicle:
1. Click "+ Add Vehicle" button
2. Fill in all required fields (*)
3. Add optional details
4. Click "Create Vehicle"
5. See success notification
6. Vehicle appears in list

Editing a Vehicle:
1. Find vehicle in list
2. Click edit icon (pencil)
3. Update desired fields
4. Click "Update Vehicle"
5. See success notification

Deleting a Vehicle:
1. Find vehicle in list
2. Click delete icon (trash)
3. Confirm in dialog
4. Vehicle becomes inactive
5. Disappears from active list

Filtering Vehicles:
1. Select vehicle type dropdown
2. Select status dropdown
3. Type in home port search
4. List auto-filters
5. Reset by clearing filters

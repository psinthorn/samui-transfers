EXAMPLE USAGE
================================================================================

Create Location:
  POST /api/tour-locations
  {
    "tourPackageId": "xyz",
    "name": "Koh Tao Snorkeling",
    "type": "WATER_ACTIVITY",
    "sequenceNumber": 1,
    "latitude": 10.3915,
    "longitude": 99.8317,
    "keywords": ["snorkel", "fish", "coral"]
  }
  Response: 201 Created with full location object

Search Locations:
  POST /api/tour-locations/search
  {
    "query": "snorkel",
    "island": "Koh Tao",
    "page": 1,
    "limit": 20
  }
  Response: Array with pagination metadata

Get SEO Data:
  GET /api/tour-locations/abc123/seo
  Response: Title, description, Open Graph, Twitter, JSON-LD

Approve Location:
  POST /api/tour-locations/abc123/approve
  {
    "approve": true,
    "notes": "Approved for publication"
  }
  Response: Updated approval status

Bulk Import:
  POST /api/tour-locations/batch-import
  {
    "tourPackageId": "xyz",
    "locations": [
      { "name": "...", "type": "...", ... },
      ...
    ]
  }
  Response: Success/failure summary per item

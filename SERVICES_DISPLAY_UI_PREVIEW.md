## Interactive States

### Default State
```
Card
├─ Box shadow: md (shadow-md)
├─ Border: 1px slate-100
├─ Opacity: 100%
└─ Scale: 100%
```

### Hover State
```
Card
├─ Box shadow: xl (shadow-xl)  ← Increased
├─ Border: 1px primary         ← Changed to primary color
├─ Opacity: 100%
├─ Scale: 100%
├─ Transition: 300ms
└─ Icon
   └─ Scale: 105% ← Grows slightly
```

### Focus State (Keyboard)
```
Card
├─ Outline: 2px primary
├─ Outline-offset: 2px
└─ Same as hover
```

### Active/Pressed State
```
Button
├─ Background: primary/90 (slightly darker)
├─ Color: white
└─ Transition: 200ms
```

```
Properties:
├─ shadow: md → xl
├─ border-color: slate-100 → primary
├─ Duration: 300ms
├─ Easing: default (ease-out)
└─ Timing: cubic-bezier(0.4, 0, 0.2, 1)

Icon Scale:
├─ From: 100%
├─ To: 105%
├─ Duration: 300ms
└─ Easing: ease-out
```

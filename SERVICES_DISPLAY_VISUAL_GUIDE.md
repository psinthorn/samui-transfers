## Hover Effects & Interactions

### Card Hover State
```
Before Hover:                     After Hover:
┌─────────────┐                 ┌─────────────┐
│  Card       │                 │  Card ✨    │  (scale up)
│  (normal)   │ ────────→       │  (lifted)   │
│  shadow: md │                 │  shadow: xl │
└─────────────┘                 └─────────────┘
```

### Icon Hover Effect
```
Icon scales from 100% to 105% on card hover
(transition: 300ms duration)
```

### Button Hover Effect
```
Button color transitions from primary to primary/90 opacity
(transition: 200ms duration)
```

### Accessibility Features
- Semantic HTML: `<section>`, `<h2>`, `<h3>`, `<button>`
- Proper color contrast for WCAG AA compliance
- Icons paired with text (not color-only indicators)
- Keyboard navigation support (buttons are native `<button>` elements)

## User Journey Flow

```
1. User lands on homepage
   ↓
2. Sees SearchSection (booking search)
   ↓
3. SEES ServicesSection (NEW) ★
   "What services do we offer?"
   ↓
4. Reads service descriptions
   ↓
5. Clicks on a service (or "Learn More" button)
   - Optional callback to filter search
   - Navigate to service detail page
   - Pre-select service type
   ↓
6. Proceeds with booking or exploration
```

## ✨ How It Works

### Expanding Groups
```
Click Group Header
    ↓
Arrow rotates 90°
    ↓
Submenu items slide down
    ↓
Items are now clickable
```

### Navigation Flow
```
Click Menu Item
    ↓
Current page highlighted in blue
    ↓
Parent group auto-expands if needed
    ↓
Page loads in main content
```

### Mobile Behavior
```
Sidebar hidden by default
    ↓
Tap hamburger icon
    ↓
Sidebar slides in from left
    ↓
Groups expand/collapse with tap
    ↓
Click menu item to navigate
```
